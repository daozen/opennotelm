# Public examples / 公开示例

`learning-notes.md` is self-written demonstration material under the repository's MIT
license. Upload it into a disposable notebook, ask what makes an experiment useful,
and try a Deck for beginners. Model calls can cost money; no provider keys are included.

`learning-notes.md` 是采用仓库 MIT 的自编资料。可在临时笔记本导入，询问实验如何设计，
或生成面向初学者的 Deck；模型调用可能收费，示例不含密钥。

Public screenshots use synthetic material and deterministic local fixtures, not user
documents or real image-model results. They demonstrate interface behavior only.
公开截图使用合成资料和本地测试模型，不使用用户资料，也不代表真实生图质量。
