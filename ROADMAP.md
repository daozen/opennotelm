# Roadmap

[简体中文](ROADMAP.zh-CN.md)

This is a direction, not a delivery-date promise. Current behavior is defined in
[user guide](docs/USER_GUIDE.md); release status is in [CHANGELOG](CHANGELOG.md).

## Public Beta

- Reproducible self-hosted releases, versioned images, clear setup and recovery docs.
- Source-grounded reading/chat/knowledge and controllable Visual Deck generation.
- Better provider compatibility reports, safe diagnostics and dependency maintenance.
- User feedback on accessibility, translation and generation reliability.

## Candidates after feedback

- More repeatable content/visual quality evaluation using rights-cleared materials.
- Better fidelity for source charts and photographs, and searchable image-based PDFs.
- Further measured improvements to generation cost, latency and partial recovery.

These candidates are not implemented commitments. Existing sources and artifacts
must remain compatible; upgrades must not silently regenerate them.

## Commercial direction

The current self-hosted release remains MIT. Possible future offerings include
managed hosting and enterprise deployment/support. No paid service, support SLA,
account system or billing integration is currently available. Hosted multi-user
services would require separate authentication, isolation and privacy design.
See [licensing and commercial use](docs/LICENSING.md).
