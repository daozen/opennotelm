## 1. 配置模型 / Configure models

首次打开应用，设置语言、Embedding 和图片三个角色。填写兼容接口的服务地址、
Model ID 和密钥，分别执行“测试并保存”。不支持模型列表接口时可手动填 Model ID。
密钥可来自部署环境，表单留空；界面不会回显已保存密钥。测试本身可能产生费用。

语言模型需要聊天和结构化 JSON 能力；扫描和插图还需要图片输入，请单独测试图片识别。
Embedding 是独立向量接口，聊天模型不会自动具有向量能力。
图片生成是另一项能力，用于默认完整图文页面。

不同角色可以使用不同服务。服务兼容 OpenAI API，不代表所有模型都支持读图、
结构化输出或清晰中文生图。连接通过只验证当次能力，不保证长资料始终生成成功。
切换 Embedding 后可查看整体及逐资料索引重建进度，失败可重试；原文与出处不变。

## 2. 导入与阅读 / Import and read

创建笔记本后可多选上传 EPUB、PDF、`.docx`、Markdown 或 TXT。逐项显示结果，
重复文件会询问处理方式。旧版 Word `.doc` 请先用你信任的软件转换为 `.docx`。

EPUB目录、PDF书签和Word标题形成章节树；没有目录的PDF不把每页当成章节。
阅读器提供前后章节/页面与原图。扫描页和插图识别使用语言模型，失败可单独重试。
OCR可能识别错误，精确引文、数字和图表请对照原文或原图。

导入公开网页时每行一个 URL，最多50条。“保存正文图片”是可选项，初始勾选；
图片处理完成前正文就可用。保留 HTML 快照，不执行脚本、不使用浏览器登录 Cookie。
登录墙、纯动态页面和禁止外链的图片可能失败；重试保留成功原图，不重新抓正文。

请确认有权导入和使用资料，不要绕过付费、登录或访问限制。网页快照和原图保存在本地。

## 3. 问答与知识 / Ask and save knowledge

问答依据所选资料/范围，点击出处查看相关完整段落并返回原文。资料不足时会提示，
不会把一般模型知识冒充资料证据。知识页可保存和更新，更新保留原页的输出语言。
笔记本中的“新内容语言”默认跟随界面，也可独立选择12种语言；引用保留原文语言。

切换界面语言不会翻译已有资料、问答或产物，新请求在提交时冻结输出语言。
保存的选择优先于浏览器偏好，首次自动匹配支持的浏览器语言。

## 4. 生成 Deck / Generate a Visual Deck

选择资料，或展开单份资料的章节树。父目录包含下级内容；所选父子范围会去重。
选择合并为一份，或者每份资料/章节分别生成，并检查生成份数与页数。
只有单个来源时可沿用来源名称；章节名称包含书名、真实目录序号和章节名。

补充说明可以要求解读深度、受众、语言和视觉风格。明确要求优先于默认展示偏好，
仍需遵守事实与范围约束。Deck可使用模型知识帮助解释；这类补充不会冒充有出处的原文。
单章默认结合已上传的全书背景；需要限制时可写“只解读本章，不联系全书”。

新 Deck 先保存理解、规划和页面文字，再生成视觉编排、整页图片与 PDF。
存在依赖的阶段仍有序；不同 Deck 和独立页面请求使用有界共享额度。
超过服务能力地增加并发，可能更慢或产生错误。

在模型设置调整任务数、服务总请求并发、Deck内容、图片识别和图片生成并发。
三项页内并发支持1–20，任务数1–8；新任务使用新设置，运行任务保留冻结值。
初次长书背景读取和多图理解可能耗时，其他章节会复用合适的已保存结果。

生成 Deck、Podcast 或思维导图时，可在“历史说明”选择已有同类产物最近使用的 20 条不重复要求，
支持跨笔记本复用。选中后替换下方文字，仍可编辑；未提交的草稿不保存为历史。
删除最后一个使用该说明的产物后，列表不再保留它。历史加载失败时仍能手动填写。

## 5. 预览、修改和下载 / Review, revise and download

在 Deck、Podcast 或思维导图中展开“生成时的自定义说明”，可查看原始要求；未填写时有明确提示。
这里只读展示，不会重新生成或修改已有产物。

点击预览图左右半边，或按↑/↓切换页面；输入框和编辑弹窗不触发切页。
“专注预览”放大查看，Escape退出。文字稿和出处在图片下方；修改文字需重新生成本页。
重写内容副本重新解读并保留原稿，视觉优化副本保留文字而重选风格。

排队或生成中的 Deck 可以停止，随后从保存进度继续；失败或部分完成时保留成功页面。
重试前先查看失败详情/生成记录。删除需确认并保留原资料；改名影响后续 PDF 下载名。
批量下载只打包符合条件的当前 PDF，不调用模型或重新导出。

默认PDF是完整页面图片，暂不支持选择/搜索正文文字。原图参与理解，但最终页面重绘；
图表数字、照片和引文可能失真。下载前核查文字稿与原文，不应仅靠图片作事实判断。
旧PDF可重新导出无损优化版本，不需要重新生图；批量ZIP最多100份/512MiB。

## 6. 常见问题 / Troubleshooting

| 问题 / Symptom | 处理 / Next step |
|---|---|
| 无法连接模型 | 检查容器到宿主网络、API 地址、密钥、模型 ID 和服务公开状态，不分享私有地址。 |
| 扫描页没有识别 | 测试语言模型图片输入，查看逐图错误并重试；图片生成不是 OCR。 |
| 模型内容无法使用 | 查看实际失败阶段和安全校验规则，使用足够能力的 JSON/读图模型；短探测不保证长文成功。 |
| 图片生成失败 | 检查安全 HTTP/错误码、限流和图片能力，降低共享并发后重试缺页。 |
| 页面文字不清 | 对照文字稿和图片，修改/重生成本页，或选择更合适的图片模型。 |
| 网页/图片无法下载 | 检查公开可访问性；不支持脚本/登录/Cookie，主动阻止私网地址导入。 |
| 报实例已运行 | 找到实际持有者并有意停止，不删除锁绕过它。 |
| 升级后异常 | 停止并保留当前数据，恢复匹配的完整备份，禁止对已迁移数据库只降级代码。 |

通过Deck失败详情或设置中的诊断下载查看安全错误信息。报告不包含原文、提示词或密钥，
但分享前仍需自己检查。请使用自编最小资料复现，不上传数据库、真实书籍或原始模型响应。
匿名统计默认关闭；无接收配置时可保存参与选择，但不会向外发送。详见[隐私](PRIVACY.zh-CN.md)。


## 生成 Podcast

在创作空间选择“生成 Podcast”，选择资料、知识页或树状章节；可合并一期，也可逐份生成。
选择双人对话或单人讲述、语言和约 5/10/20/30/60 分钟。补充说明从首次阅读生效；
实际时长会受内容和语速影响，不是精确分钟承诺。

生成音频前配置可选“语音模型”：填写 OpenAI-compatible Speech 地址、模型及两种声音，
或选择 Gemini Interactions 原生语音；保存时会实际测试两种声音。没有语音服务也可先生成
台词，编辑后再合成音频。[本地 Qwen3-TTS](QWEN_TTS.md) 独立部署，不是主应用强制依赖。

停止/继续会保留已完成段落和音频。编辑台词后复用未变部分，旧音频在新版本完成前明确标识。
可查看出处和节目使用的资料/章节；播放器支持换页持续播放、倍速及章节跳转。
支持 MP3、结构化台词及多节目 ZIP 下载。失败详情只有运行信息，不包含台词、原文和密钥。
删除节目保留原始资料。更换模型/声音后不能混入旧任务；请恢复原配置继续，或新建节目。


## 统一创作空间与思维导图

点击“全部产物”，在同一处生成和查找 Visual Deck、Podcast、思维导图。可按名称搜索、
类型/状态筛选，查看时用“切换产物”快速跳转，“返回创作空间”回到列表。每份可停止、
继续或删除，已完成文件可混合批量下载；删除产物保留原始资料。

选择“生成思维导图”，选取资料、知识页或树状章节，可合并一份或分别生成。选择语言、
填写自定义说明，也可从历史快捷填入。章节导图自动利用整本书背景，只调用语言模型，
无需图片或语音生成服务。

点击节点查看解释与原文出处；分支可展开收起，画布可拖动、缩放或适应大小。
指针放在画布内，滚动鼠标滚轮或在 Mac 触控板上双指捏合即可围绕指针缩放；也可用
加减按钮。画布外仍可正常滚动页面。“专注预览”
提供更大空间，“文字提纲”适合小屏阅读完整层级。导图及选中节点有独立地址，刷新保留。
支持完整图形 SVG、文字 Markdown 和带来源引用映射的 JSON 下载；批量 ZIP 中导图为
Markdown。查看页也可查看生成说明、来源和失败详情，停止/继续保留已保存的进度。
