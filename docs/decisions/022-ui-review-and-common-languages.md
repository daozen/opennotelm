# 022 — 系统 UI 审查与常用语言扩展

日期：2026-10-03。状态：已实现；验证结果见 ACCEPTANCE。
用户要求系统优化布局、文案、按钮认知和交互，确认新增十种常用语言。

## 决策

保留桌面三栏信息结构，在1100px及以下改为显式分区切换，不卸载非当前面板，
避免切换列表时丢失问答/知识草稿。打开新的路由对象自动回到内容工作区。
既有刷新、前进/后退、章节与稳定slide URL不改变。

下载、预览和生命周期操作保持可直接访问；重新导出和创建两种副本收进“更多操作”，
区别仅换视觉与重新解读，明确新副本保留原稿。页级修改保持原有API和证据约束。
用共用Modal统一焦点、背景、滚动和关闭行为，嵌套引用仅操作最上层窗口；忙碌时
禁止Escape关闭。页编辑关闭使用已有未保存保护。删除/复用错误放在当前确认框。

支持zh-CN、en、zh-TW、ja、ko、es、fr、de、pt-BR、ru、ar、hi。
资源本地随应用打包，无运行时翻译服务；服务器语言偏好仍为实例级，与遥测同意
独立更新，无SQL迁移。默认zh-CN，保留已有选择。阿拉伯语设置html dir=rtl，
布局使用逻辑间距、方向导航图标；原文/用户文本dir=auto，不翻转图像或改写资料。
新Deck内容语言初值仍为当时界面语言，可单独设置，不改变已有产物语言。

完整发现/处理清单见 [UI_REVIEW](../UI_REVIEW.md)。该决策扩展原有双语界面范围，
补充014预览/操作交互，不改变模型生成、缓存、并发、队列或数据安全契约。
