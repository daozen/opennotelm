# 035 — 首次界面语言跟随浏览器偏好

日期：2026-10-04。用户要求默认语言由浏览器或系统语言决定，取代022固定简体中文默认。
034新内容默认跟随界面保留，因此首次生成也跟随自动匹配结果。

浏览器navigator.languages按顺序匹配，navigator.language作为后备。浏览器通常从OS
继承偏好，不读取服务器OS语言，也不新增原生系统接口。Intl.Locale规范化BCP47，
地区变体归并现有12目录；中文script Hans/Hant优先于地区，无script时TW/HK/MO繁体，
其他中文简体。现有葡语目录为pt-BR，因此pt/PT同样使用它。无可用匹配回退英文。
畸形标签跳过，不阻止匹配下一偏好。检测不调用模型或外部翻译服务。

GET preferences在无已存language时返回ui_language:null。统计部分更新只持久化
真实已有值及本次更改，不顺便写入隐式zh-CN；返回仍包括nullable语言。PUT显式null
仍拒绝，手动语言选择只接受现有12种。手动保存值优先于浏览器，实例级偏好契约保留；
旧版本曾保存的值全部保留，不能猜测某个zh-CN是旧默认还是用户选择后删除。

脚本初始化使用有效缓存或自动检测；服务器加载后已存选择是权威，无选择则重新检测
并清空旧cache。自动匹配不写服务器或cache，换浏览器时可用该浏览器偏好；选定语言
保存后跨浏览器/重启保持。现有资料、草稿、生成内容、原文引用、统计同意不因此改变。
无迁移、新目录或“恢复自动选择”操作；该规则只改变没有保存选择时的默认行为。

验证覆盖12种直接匹配、地区/文字优先、偏好顺序/畸形/英文fallback、无浏览器存储、
未保存时不自动PUT、已存选择优先与RTL，以及隐私更新/重启不填充locale。浏览器模拟
fresh GET契约，显式PUT与另一个浏览器读保存值走真实测试API；不删除共享验收数据库
来伪造首次环境。完整执行/发布证据见ACCEPTANCE。
