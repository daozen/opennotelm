# 034 — 新内容语言与界面本地化补全

日期：2026-10-04。用户要求修复多语言核查缺口，并让生成语言支持现有全部界面语言。
本决策补充022，取代“仅Deck可显式设置新生成语言”的行为；界面切换不改旧内容仍有效。

## 选择与兼容

笔记本共享“新内容语言”：默认跟随界面，可单独选择简/繁中文、英文、日、韩、西、法、
德、巴西葡语、俄、阿拉伯语、印地语。适用于新问答、知识页、摘要/提纲和Deck初始值。
它保存在当前Workspace组件，刷新回默认；用户显式选择不随界面切换覆盖，草稿不清空。
Deck创建框仍可独立修改；创建框打开后不因界面变化重置正在填写的语言。
语言提交时解析并冻结，后台不在执行时读取UI偏好。已有产物不自动翻译。
旧API请求/队列缺失或null保留原行为，不迁移数据库。Knowledge更新始终保持既有页
metadata语言；显式请求改变拒绝409，旧页无metadata保持原有页面语言提示。

## 事实与内容约束

允许生成的标题/解释使用所选语言，不翻译原文引用冒充逐字引文，不改变CitationSpan
身份与offset，也不因此赋予Chat/Knowledge/转换Deck的模型知识引申权限。
白名单语言名生成系统指令；不把用户自由文本拼成语言提示。每层Synthesis和最终输出
使用相同语言，缓存哈希覆盖语言改变，Chat上下文预算包含额外指令。

## 本地化缺口

模型设置技术标签翻译为普通用户可理解的服务地址/访问密钥/模型ID；英文目录保留
对应API名称。诊断日期、时长按应用locale，资料不足消息读取时通过typed status展示
译文，canonical英文控制字符串仍保存用于验证，用户相同文字不翻译。默认生成中的
知识页标题作为状态本地化，用户标题不改写。12目录键和插值保持一致。
Docker提供Noto core及既有CJK字体；没有新增外部翻译服务或图片文字校对。

## 回归发现的独立缺口

032模型切换忽略未关联资料符合范围，但重新关联时没有补当前索引。关联事务现在只
为该资料补排缺失/过期source_reindex，重复关联复用活动任务；不解析文件或OCR。
此修复补充032，不改变重建范围和事实层约束。

## 验证边界

全部12种的后台提示/任务payload/metadata、分层压缩/缓存、引用身份与原文保护使用
隔离资料和测试provider验证；浏览器覆盖跟随/显式选择、草稿、语言请求、Knowledge、
临时转换及Deck初始选择、手机布局和RTL。具体执行记录见ACCEPTANCE Stage50。
真实翻译准确性、阿拉伯语/印地语生图文字质量仍取决于用户模型，不声称完成母语审校。
