# 025 — Deck预览图与键盘翻页

日期：2026-10-04。扩展[014](014-deck-controls-and-preview.md)的预览交互。
用户要求点击预览图左右切换上一张/下一张，不显示图上的按钮，并用键盘上下键切页。

左右各半幅覆盖透明语义button，无文字/图标/悬停背景；保留可访问名称、键盘焦点
轮廓及`aria-keyshortcuts`。物理左半边为上一页，右半边为下一页，RTL也不镜像。
图像原来的高清打开行为移到独立“查看高清页”链接；原工具栏/缩略图继续可用。

普通和专注预览共用同一页选择函数，按当前slides数组顺序到邻页，边界禁用/停住。
沿用`onSelectSlide`和稳定slide ID URL，刷新/历史、滚动重置与缩略图同步保持原契约。
切页不是修改页序，不调用生成/重排API，不改已有图片/PDF/引用或模型设置。

已加载页的Deck注册document键盘监听，↑上一页、↓下一页，处理后阻止浏览器滚动。
输入/选择/可编辑区域、控件自带方向键、IME、组合键、已处理事件和打开的Modal
均不触发切页；卸载移除监听。Escape和Tab仍由现有专注预览/弹窗处理。

图片在新的相对定位容器内，不能再按img.offsetTop预算高度；改按图片/预览容器矩形
位置加预览scrollTop计算可用高度，维持桌面、平板及手机专注预览的图像完整可见。
标签仅组合现有已翻译的“上一页/下一页/页面预览”，无需新增语言键或迁移。

测试与本机更新证据见[ACCEPTANCE](../ACCEPTANCE.md)的Deck preview navigation。
