# 许可与商业使用

[English](LICENSING.md)

OpenNoteLM 自有代码采用 [MIT](../LICENSE)，允许按条款商用、修改、分发和收费托管，
副本或主要部分需保留版权与许可声明。当前 MIT 版本不要求商业使用付费或审批。

依赖、字体、图标、浏览器等保留各自许可，见[第三方声明](THIRD_PARTY_NOTICES.zh-CN.md)。
MIT 不替代这些条款。用户资料与生成产物不会因仓库许可自动变成 MIT，
使用取决于资料权利及模型服务条款。仓库不包含预训练权重或付费 API 密钥。

## 贡献权利

按 MIT 接收贡献，并通过 DCO 签署确认有权提交；作者保留版权，不转让版权，
目前不要求 CLA。见[贡献规范](../CONTRIBUTING.zh-CN.md)。
DCO 不等于赋予特别的未来再授权权利。他人的 MIT 贡献保留声明。
未来许可策略必须尊重已有授权；已经按 MIT 分发的版本仍可按 MIT 使用。

## 品牌与未来服务

代码许可不授权冒充官方背书。独立 fork 和服务应清晰标注运营者，
避免被误认为官方 OpenNoteLM 服务；这里不声称拥有注册商标。

未来托管、企业支持或额外商业产品可采用单独服务条款。
本文不会开启支付、账号、统计，也不会增加当前 MIT 版本的使用限制。
项目独立于 Google 和 NotebookLM，不代表其认可；产品名称属于各自权利方。

MIT 及第三方许可以保留的原文为准；本页是使用说明，不替换许可法律文本。
