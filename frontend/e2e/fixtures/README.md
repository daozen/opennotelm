# Synthetic test fixtures / 合成测试资料

The EPUB, DOCX, PDFs, Markdown and text files here are small handcrafted/generated
test inputs about learning, time and practice, licensed with this repository under MIT.
They are not excerpts from uploaded user books. Embedded illustrations are simple
test graphics/scanned sample text; generated fixture fonts retain their own licenses.

The EPUB intentionally contains inert script/iframe/HTML injection strings to test
that imports treat markup as untrusted data. Do not execute these strings.
PDFs exercise glyph fragmentation, page scans, bookmarks and nested chapter boundaries;
DOCX exercises styles, tables and inline images. No model keys or user originals belong here.

这些 EPUB、Word、PDF 和文本是关于学习/时间/练习的自编测试输入，采用仓库 MIT，
不是用户书籍摘录。插图是简单测试图形或扫描示例；嵌入字体保留各自许可。
EPUB 中刻意放入不执行的脚本/iframe/HTML 字符串，验证非可信内容处理，不应执行。
PDF 覆盖碎字、扫描、书签和目录，Word 覆盖样式/表格/图片，不包含密钥或用户原稿。
